ローカルのワークフローでは、Git をほぼ [jj](https://jj-vcs.github.io/jj/) に切り替えて数か月使っています。全体として想像以上に安定していて、手になじみました。以前は「できるのは分かっているけど面倒」で後回しにしていた小さな整理も、今はコストがとても低くなっています。

さらに重要なのは agent 協業の面です。複数の AI agent と人が一緒にコードを触るとき、jj の操作モデルのおかげで履歴をより明確に保ちやすく、ブランチ管理の負担も減ります。途中で振り返ったり思考を調整したりするのも簡単です。私にとっては、従来の Git よりもこの時代の思考様式に合っています。

バージョン管理を見直しているなら、こちらの完全版もどうぞ：[jj for Agent Era](https://onevcat.com/2026/03/jj-for-agent-era/)。実践の細部と判断の根拠をより丁寧に書いています。
