特斯拉相对于其他车，可玩性要高不少。通过 [FleetAPI](https://developer.tesla.com/docs/fleet-api/getting-started/what-is-fleet-api) 和 [Telemetry](https://developer.tesla.com/docs/fleet-api/fleet-telemetry) 的相关能力，配合上 Tesla Developer 每个月赠送的 $10 额度，基本上可以实现包括行程路径，实时速度，电池情况等车辆信息和数据的全链路收集。更有意思的是[虚拟钥匙](https://developer.tesla.com/docs/fleet-api/virtual-keys/overview)，它可以让车辆和私有服务器配对，并通过 API 对车辆进行一定程度的操控。配合上之前搭建的[猫娘团队](https://ai.onev.cat/articles/zh/2026-02-22-openclaw-multi-agent-team/)，我现在可以通过 Discord 和 agent 的对话，很方便地让 agent 研究路线，寻找停车场和周边情况，然后向车辆发送导航或者按照出发预计控制空调等，玩得不亦乐乎。与其说是换了一个代步工具，其实更像是买了个大号的科技玩具。
