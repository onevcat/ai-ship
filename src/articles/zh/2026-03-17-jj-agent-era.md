我在本地工作流里已经把 Git 基本切到 [jj](https://jj-vcs.github.io/jj/)，用了几个月，整体体验比预期更稳也更顺手。很多过去“知道能做但懒得做”的小整理动作，现在成本变得很低。

更关键的是在 agent 协作上：当多个 AI agent 和人一起改代码时，jj 的操作模型让我更容易保持历史清晰、减少分支管理负担，也更容易在中途回看和调整思路。对我来说，它确实比传统 Git 心智更贴合这个时代。

如果你也在重新思考版本管理，可以看我这篇完整分享：[jj for Agent Era](https://onevcat.com/2026/03/jj-for-agent-era/)，里面把实践细节和判断依据写得更完整。
