我在本地工作流里已经把 Git 基本切到 [jj](https://jj-vcs.github.io/jj/)，连续用了几个月，感觉很好。最大的变化不是“命令更少”或者“操作更快”，而是它给出的版本管理心智模型，更贴近我现在的开发节奏。

Git 是非常优秀、也已经被验证了二十年的协作系统；但它承载的是上一代开发组织方式。到了 agent 时代，很多日常动作和历史管理需求都变了，而 jj 在这部分给我的感受是：更顺着思路、更容易整理历史，也更适合频繁迭代与回溯。

这并不是在否定 Git，而是我在当前工作流下做出的选择。如果你也在重新思考版本管理，可以看我这篇完整分享：[jj for Agent Era](https://onevcat.com/2026/03/jj-for-agent-era/)，里面把实践细节和判断依据写得更完整。
